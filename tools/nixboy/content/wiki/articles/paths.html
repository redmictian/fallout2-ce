A path names a file or directory. Before changing files, establish where you are and which path your command will use.

Three useful starting points

FormMeaningExample
Starts with /Absolute path, starting at the filesystem root/tmp/route.txt
No leading /Relative path, starting at your current directorynotes/route.txt
Starts with unquoted ~/Bash expands ~ to your home directory~/notes/route.txt

. refers to the current directory; .. refers to its parent. Use pwd to display your current directory and ls to inspect names before choosing a command.

Try a small workspace

These commands create a separate example directory in your lab home. The redirection writes a short example file; running it again replaces that file.

mkdir -p ~/wiki-demo/notes
cd ~/wiki-demo
pwd
printf 'Route checked\n' > notes/route.txt
ls notes
cat ./notes/route.txt
cd ..

mkdir -p creates missing parent directories. After cd ~/wiki-demo, the relative path notes/route.txt names the same example file as ~/wiki-demo/notes/route.txt.

Apply the idea

When reading a challenge, identify the starting path, destination, and whether the original must remain. You can practice this with Prepare a delivery directory. The lab resolves its own filenames, so read its instructions before acting.
