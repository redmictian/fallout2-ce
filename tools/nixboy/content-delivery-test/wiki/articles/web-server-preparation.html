URL/filesystem mapping root appends URI; a prefix alias replaces the matched prefix; exact/longest prefix/regex selection and ^~ have documented order Use unrelated /manual/ and /downloads/ data, predict concrete paths; contrast a slash-bounded prefix with a near-prefix URL. Access and listing Ordered first-match allow/deny; local access directives replace inherited access lists; directory listing and index resolution are separate from file readability Two real clients read the same OS-readable file; reverse two rules, then introduce a local override of a parent list. Observe an actual denial rather than network refusal. Compare autoindex with/without a real index file.
